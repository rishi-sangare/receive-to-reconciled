# The pain atlas

> Generated by the export script from `research/data/pains.csv` and `research/data/pain-map-items.csv`. Do not edit by hand.

We mapped **56 distinct problems** that small businesses hit between sending an invoice abroad and closing their books. They come from **429 sourced items** (325 in the main run, 104 in a follow-up). Each problem is scored on six measures from 1 to 5, plus 2 if fixing it stops it from coming back, for a maximum of 32. How the scores work is explained in [the research method](08-research-method.md#scoring).

## How to see the evidence for a problem

Open [`research/data/pain-map-items.csv`](../research/data/pain-map-items.csv) on GitHub and filter the `pain_id` column by the problem ID (for example `A01`). Every row has the quote, the link, the date and whether it was re-checked.
